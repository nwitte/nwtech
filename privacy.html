Privacy policy

NW Tech. Effective October 16, 2026.

NW Tech is a set of personal tools used only by their owner. This policy explains what Google account data the tools access and how it is handled.

Who uses NW Tech

Only the owner. The tools are not offered to the public, and no other person's account is connected.

Data accessed

With the owner's permission, NW Tech can access the owner's own Gmail account to:

  • search and read messages,
  • apply and remove labels, including archiving messages.

It also reads the basic profile information (name and email address) that Google provides at sign-in, to confirm which account is connected. NW Tech does not send email, create drafts, or change account settings.

How data is used

The data is used only to organize the owner's own mail and to keep the owner's personal task lists current. Processing happens on the owner's computer. To carry out tasks the owner asks for, message content may be processed by an AI assistant service the owner uses (Anthropic's Claude), solely for those tasks.

Sharing

Google user data is not sold, not used for advertising, and not shared with anyone other than the processing described above.

Storage and retention

Sign-in credentials are stored only on the owner's computer. NW Tech keeps no separate copy of email content beyond short-lived working files on that computer.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

NW Tech's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be sent to the support email shown on the Google sign-in screen for this app.
